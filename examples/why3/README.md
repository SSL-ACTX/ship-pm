# Why3 Verification Platform Example

This example demonstrates program specification, verification condition generation, and automated SMT proving using **Why3**.

## Prerequisites

- `adacore/why3` (or `why3`):
  ```sh
  ship i adacore/why3
  ```
- An SMT solver (such as `z3`, `cvc5`, or `alt-ergo`):
  ```sh
  ship i z3
  ```

## Running the Example

```sh
bash examples/why3/run.sh
```
